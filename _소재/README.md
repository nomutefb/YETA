# `_소재/` — 원본 소재 임시 보관소(미가공 업로드)

> **왜 있나**: 웹·앱에서 이미지·영상을 올리면 기본 경로가 **레포 루트**다. 그렇게 쌓인 미가공 파일이 루트를 어지럽혀 260726에 이 폴더로 모았다(Q.95 · 287차). **앞으로 미가공 업로드는 여기로.**

## 이건 정본이 아니다
- 캐릭터 이미지 **정본 = `viewer/characters/season/<캐릭터id>/{main,dokkaebi,…}/<감정>/`** · 목록 파일 `media.json`은 **손으로 안 고친다**(빌더 산출 = D2-1) → 사진을 넣고 `python3 shared/build_season_media.py`로 재생성.
- 얼빡(프사)은 파일명에 `face`를 넣어 배경 풀에서 제외한다(`check_refs` 얼빡 배경 게이트).
- 여기 파일은 **가공 전 원재료**라 앱이 읽지 않는다. 반영이 끝난 소재는 지워도 되지만, **삭제는 운영자 승인 사항**(D2)이라 세션이 임의로 비우지 않는다.
